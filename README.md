# Лабораторная работа №2 — Создание запросов

**Дисциплина:** Базы данных  
**Выполнил:** Кораблёв Кирилл  
**Вариант:** 25  
**СУБД:** PostgreSQL

## Цель работы

Закрепить навыки составления и выполнения SQL-запросов для выборки и обработки данных, использования соединений таблиц, агрегатных функций, а также команд добавления, изменения и удаления записей.

## Предметная область

Учёт почтовой корреспонденции. Используется база данных из лабораторной работы №1 со схемой `korablev25` и двумя связанными таблицами:

- `correspondence_types` — виды корреспонденции, тип упаковки и допустимые диапазоны веса и габаритов;
- `correspondence` — почтовые отправления, их трек-номера, вес, размеры, код отправителя и стоимость марок.

## Выполненные задания

| № | Задание | Реализация |
|---|---|---|
| 1 | Вывести трек-номера отправлений в конвертах | `SELECT`, `INNER JOIN`, `WHERE`, `ORDER BY` |
| 2 | Найти виды корреспонденции с пропорциональными средними значениями длины, ширины и высоты | `AVG`, `ROUND`, `GROUP BY`, `HAVING` |
| 3 | Создать таблицу с отправлениями в конвертах, их размерами и сведениями о видах корреспонденции | `CREATE TABLE AS SELECT`, `JOIN`, `PRIMARY KEY` |
| 4 | Добавить посылки, размеры которых выходят за установленные пределы | `INSERT INTO ... SELECT`, `NOT BETWEEN`, `ON CONFLICT` |
| 5 | Увеличить габариты на 1 см для посылок в конвертах с дробным весом | `UPDATE`, `TRUNC` |
| 6 | Удалить посылки с более чем одним пробелом в начале или конце трек-номера | `DELETE`, регулярное выражение `~` |
| 7 | Подсчитать количество различных видов упаковки для конвертов, бандеролей и посылок | `COUNT(DISTINCT)`, `JOIN`, `WHERE` |

В скрипт также включён дополнительный запрос с `WITH`, `UNION ALL` и `GROUP BY` для вывода количества видов упаковки по группам отправлений.

## Создаваемая таблица

В ходе работы формируется таблица `korablev25.envelope_selection_25`. Она содержит выбранные отправления, их вес и габариты, сведения о типе корреспонденции и допустимых размерах. Изменения по заданиям 4–6 выполняются в этой таблице; исходные таблицы лабораторной №1 не изменяются.


## Порядок запуска

1. Открыть **pgAdmin 4** или другой SQL-клиент и подключиться к PostgreSQL.
2. Выбрать базу данных `kirill_korablev_25` (или базу, в которой создана схема `korablev25`).
3. Если первая лабораторная ещё не выполнена, запустить `01_lab1_variant25.sql`.
4. Открыть `02_lab2_variant25.sql` в **Query Tool** и выполнить скрипт целиком.
5. Просмотреть результаты запросов и проверить таблицу `korablev25.envelope_selection_25`.

Для просмотра итоговой таблицы:

```sql
SELECT *
FROM korablev25.envelope_selection_25
ORDER BY track_number;
```
